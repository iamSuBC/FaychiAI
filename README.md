# FaychiAI

> 语义级浏览器内容过滤扩展 —— 一次设置、全网站生效，用 AI 语义理解替你屏蔽剧透、焦虑、引战等干扰内容，重新掌控自己的信息流。

FaychiAI 基于 Manifest V3，支持 Chrome / Edge（及所有 Chromium 内核浏览器）。区别于传统「关键词屏蔽」，它用语义识别替代字符串匹配，能识别暗喻式剧透、同义表达、指代类内容，并支持三级屏蔽强度。

## 功能特性

- **关键词 / 正则规则**：本地即时生效，无需任何配置
- **AI 语义识别**（可选）：识别「最后主角牺牲了」这类不提名字的暗喻式剧透、贩卖焦虑话术，接入任意 OpenAI 兼容接口（DeepSeek / 通义千问 / GLM 等）
- **三级屏蔽强度**：轻度遮罩（点击展开）/ 中度模糊（点击查看）/ 重度移除
- **动态内容支持**：对无限滚动、短视频信息流等懒加载内容自动监听处理
- **配置导入导出**：一键备份 / 恢复规则
- **本地优先**：关闭 AI 时全部在本地处理，内容不外传

## 安装（本地加载）

### Chrome
1. 地址栏输入 `chrome://extensions` 回车
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择 `extension` 目录

### Edge
1. 地址栏输入 `edge://extensions` 回车
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」，选择 `extension` 目录

## 快速上手

1. 点击工具栏 FaychiAI 图标打开弹窗
2. 输入要屏蔽的词（如「剧透」），点「添加」
3. 打开任意命中该词的网页，内容会被自动遮罩

想识别暗喻、同义类内容：进入「设置」→ 开启「AI 语义识别」→ 填入 Base URL / API Key / 模型 → 点「测试连接」。

## 目录结构

```

├── extension/                    # 浏览器扩展（Manifest V3）
│   ├── manifest.json
│   ├── icons/                    # 扩展图标
│   └── src/
│       ├── shared/               # 常量与存储读写
│       ├── content/              # DOM 捕获 + 屏蔽渲染
│       ├── background/           # Service Worker：AI 分类网关 + 统计
│       ├── popup/                # 弹窗：开关 / 强度 / 规则
│       └── options/              # 设置页：规则 / AI 配置 / 导入导出
├── FaychiAI-开发文档.md           # 技术方案与需求
└── 使用说明.md                    # 面向用户的使用手册
```

## 技术栈

Manifest V3 · 原生 JavaScript（无构建依赖）· chrome.storage · OpenAI 兼容大模型接口

## 路线图

- **Phase 1 · MVP**：AI 智能防剧透，适配 Top5 站点
- **Phase 2 · 功能拓展**：全场景自定义过滤、多模型分级、跨平台偏好同步
- **Phase 3 · 生态扩张**：本地轻量模型、B 端合作、移动端适配

## 说明

当前为 MVP 版本（v0.1.0）：AI 语义识别需自备大模型 API Key；未含账号登录、订阅付费与跨设备同步。
